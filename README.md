# DRIFT FESTA — 文化祭用 3D ローポリ カーレース

ブラウザで動く後方視点の 3D カーレースゲームです。文化祭で PC を1台置いて、
小さい子から大人までその場ですぐ遊べることを目標にしています。
**実行時はインターネット接続不要 (完全オフライン)** です。

- PURE RACE: 1〜2人 (左右分割画面) + CPU で合計 2〜8 台。周回コースは3周、一本道コースはスタート → ゴール
- BATTLE DUEL: 1人 vs CPU。銃とアイテムで妨害しながらレース
- 架空の車 10 台 (FF / FR / MR / AWD)、**コース 24 個** (周回コース 18 + 一本道 POINT TO POINT 6。それぞれ固有のギミックと見せ場)、
  CPU の強さ 4 段階 (最強 ULTIMATE まで)
- 音はすべて Web Audio API で実行時に合成 (音声ファイルなし)。**BGM はコースごとのオリジナル曲を実行時に作曲・合成** (著作権・ライセンスの心配なし)

## 必要環境

| 項目 | 推奨 |
|---|---|
| OS | Windows 10/11, macOS 13 以降 (Linux も可) |
| ブラウザ | **Google Chrome 最新版** (Edge / Firefox / Safari も動作想定) |
| Node.js | **v20 以上 (推奨 v22 LTS)**。開発・ビルド時のみ必要 |
| npm | Node.js 付属のもの (v10 以上) |
| GPU | WebGL2 対応。内蔵 GPU でも「低」画質なら動作 |
| 入力 | キーボード (BATTLE DUEL はマウスも) |

## セットアップ

インターネットに繋がる環境で1回だけ実行します。

```bash
git clone <repository-url>
cd club_game_proj
npm install
```

> npm install で `EACCES` (権限エラー) が出る場合は、npm のキャッシュ権限の問題です。
> `sudo chown -R $(id -u):$(id -g) ~/.npm` を実行するか、
> `npm_config_cache=/tmp/npmcache npm install` のように別のキャッシュ場所を指定してください。

## 開発・ビルド・起動

```bash
npm run dev        # 開発サーバー http://localhost:5173 (デバッグ機能 ON)
npm run build      # 型チェック + 本番ビルド (dist/ に出力)
npm run preview    # ビルド成果物を http://localhost:4173 で確認
npm test           # 自動テスト (Vitest)
```

## 文化祭当日の起動 (担当者向け)

**当日はこの章だけ読めば OK です。インターネットは不要です。**

1. PC の電源を入れ、ターミナル (Windows は「PowerShell」または「コマンドプロンプト」) を開く
2. 次を入力して Enter

   ```bash
   cd club_game_proj   # このフォルダの場所に合わせる
   npm run festival
   ```

3. 自動でブラウザが開き、タイトル画面が出ます (開かない場合は Chrome で `http://localhost:4173` を開く)
4. 画面をクリック → **F11** (Mac は Ctrl+Cmd+F) で全画面にする。ゲーム内の「設定 → フルスクリーン」でも可
5. 終わるときはターミナルで **Ctrl + C**

`npm run festival` は「本番ビルド (デバッグ機能 OFF) → ローカルサーバー起動 → ブラウザを開く」を行います。
2回目以降でビルド済みなら `npm run festival:serve` でビルドを省略して起動できます。

- 結果画面で 60 秒操作がないと自動でタイトルへ戻ります (設定で変更可)
- 画質が重いと感じたら「設定 → グラフィック品質 → 低」
- 事前準備: 前日までに `npm install` と `npm run festival` を一度成功させておくこと
- 来場者向けの遊び方スライド (PowerPoint): `docs/festival/how-to-play.pptx`。待ち列のモニターなどで流す

## 操作方法

### PURE RACE (1人)

| キー | 動作 |
|---|---|
| A | 前進 |
| F | ブレーキ / 後退 |
| E | 右 |
| W | 左 |
| Space | ドリフト |

### PURE RACE (2人・左右分割)

| | Player 1 (左画面) | Player 2 (右画面) |
|---|---|---|
| 前進 | **A** | ↑ |
| 後退 | **F** | ↓ |
| 右 | **E** | → |
| 左 | **W** | ← |
| ドリフト | **Space** | Enter |

> **A / F / E / W** (前 / 後 / 右 / 左) は、小さい子でも小指〜人差し指で操作しやすいよう
> 意図的に決めた配置です。一般的な WASD に変更しないでください。1人プレイでも矢印キーではなく A/F/E/W です。

### BATTLE DUEL (1人)

| 操作 | 動作 |
|---|---|
| A / F / E / W | 前進 / 後退 / 右 / 左 |
| Space | ドリフト |
| マウス移動 | 照準カーソルを動かす (カメラは自動) |
| 左クリック | 発砲 (長押しで連射) |
| 右クリック | 照準を画面中央へ |
| ホイール | アイテム選択 |
| ホイールクリック | 選択中のアイテムを使う |
| 4 | 選択中のアイテムを捨てる |

ゲーム画面をクリックするとマウスカーソルが画面内に固定されます (Esc で解除 → ポーズ)。

### キー設定

「設定 → キー設定」で、1P (1人プレイ・2人の P1・BATTLE DUEL) と 2P の運転キー (前進 / 後退 / 右 / 左 / ドリフト) を変更できます。
項目を選んで割り当てたいキーを押します。使用中のキーを選ぶと入れ替わります。「すべて初期設定に戻す」で上の表の配置に戻ります。
`npm run festival` で起動したときは毎回初期設定に戻ります (前の人の変更が残りません)。

### 共通

- **Esc**: ポーズ (再開 / リスタート / 設定 / タイトルへ)。2人プレイ中もゲーム全体が止まります
- メニュー: 矢印キー + Enter、Esc / Backspace で戻る。マウスでも操作可

### コース (24)

コースは2種類あります。コース選択では最初にタイプを選び、次にやさしい順に並んだカードから選びます
(カードに ★・距離・目安タイム・特徴のアイコン、横に コース図・見どころ・攻略 を表示)。

- **CIRCUIT (周回コース)**: 同じコースを3周してゴール
- **POINT TO POINT (一本道)**: スタートからゴールまで一気に走る。周回表示の代わりに「進行度 % / ゴールまでの残り距離 / 区間名」を表示。
  ミニマップは自分の周りを拡大して追従し、下に START → GOAL の進行バー (全車の位置) を出します

★ の意味: ★1 とてもかんたん / ★2 はじめての人向け / ★3 ふつう / ★4 むずかしい / ★5 上級者向け
(文化祭は初めての人が多いので ★2 のコースが一番多い: ★1×1 ★2×9 ★3×8 ★4×5 ★5×1)

### CPU の強さ

| 表示 | 特徴 |
|---|---|
| WEAK | やさしい。ブレーキが早くミスも多い |
| NORMAL | ふつう。ほどよいライバル |
| STRONG | つよい。理想ラインに近くミスが少ない |
| **最強 ULTIMATE** | ほぼミスしない正確な走り。ブーストパッドを狙い、氷や障害物のタイミングも読む。**車の性能アップ・ラバーバンド・ワープなどのズルは一切なし** |

### ルール

- 周回コースは3周、POINT TO POINT はゴールラインまで。最初にゴールした車が勝ち
- 順位: 周回コースは「周回 → チェックポイント → 次のチェックポイントまでの進み具合」、POINT TO POINT は「通過したチェックポイント → 進行度」
- 前の車の真後ろにつくと **SLIPSTREAM** (空気抵抗が減って少し速くなる。人間も CPU も同じ条件)
- 柵のない場所から落ちると、最後に通過したチェックポイントへ戻り **2 秒間操作不能** (`physics.ts` の `respawn.lockSeconds`)
- BATTLE DUEL: タイヤHP 100 (車全体で1つ)。0 になると最高速度 50%。Recovery で全回復
- アイテム最大3個。Recovery / Boost (8秒 最高速+20% 弾速+40%) / Gun (銃+弾10発)

## デバッグ方法

`npm run dev` で起動するとデバッグ機能が有効です。本番ビルドでも URL に `?debug=1` を付けると有効
(`npm run festival` のビルドでは常に無効)。

| キー | 内容 |
|---|---|
| F3 | 情報オーバーレイ: FPS・速度・速度ベクトル・ステア/ブレーキ入力・グリップ・横滑り角・ドリフト量・チェックポイント・NPC の ID / 難易度 / 性格 / 目標速度 / 状態 / ミス / 回避 |
| F6 | 3D 表示: NPC のレーシングライン・現在のターゲット点・チェックポイント・コライダー・速度ベクトル・アイテムボックス範囲・弾丸軌道・**Road Safety Corridor (水色)・地形が上がり始める線 (緑)・地形/背景物の侵入点 (赤い柱)・スタート (緑) / ゴール (赤) の柱**・夜のヘッドライト範囲 |
| F4 | 情報を表示する車を切替 |
| F8 | プレイヤー車を自動運転 (動作確認用) |
| F9 | 時間の早送り x1 / x4 |

F6 の3D表示では、コースギミック (ブーストパッド範囲・路面タイプ・変形区間・横風・コンベア・ジャンプ台・
動く障害物の当たり判定) と、NPC が狙っているギミックへの線も表示されます。F3 のオーバーレイには
路面の種類とグリップ倍率、変形状態、NPC の判断状態 (decision) とギミック利用傾向、**コース種別・道幅・路肩・いまいる場所のギミック・
安全帯への侵入数・進行度 / 残り距離 / 区間・ヘッドライトの範囲** が出ます。

**レースへ直接入る (開発用):** URL にパラメータを付けるとメニューを飛ばしてレースを始められます。

```text
http://localhost:5173/?debug&race=aqua&mode=pure&cars=6&diff=ultimate&players=2&car=apex86&at=0.4
```

`race` = コースID (aurora / touge / harbor / aqua / skyline / frost / magma / neon / jungle / toybox / tokyo / alpine /
coastal / desert / northern / europe / airport / volcano / mall / school / cloud / space / rain / windfarm)、
`diff` = weak / normal / strong / ultimate、`at` = 開始位置 (コース全長の割合 0〜1。ギミックの確認に便利)。

ブラウザのコンソールで `__app.stats` を実行すると、レース回数・GPU のジオメトリ/テクスチャ数・ヒープ使用量を確認できます (メモリリーク確認用)。

## 設定ファイル (バランス調整)

ゲームバランスは **`src/config/` の数値を変えるだけ**で調整できます (ロジックの変更は不要)。

| ファイル | 内容 |
|---|---|
| `cars.ts` | 10 車種の最高速度・加速・ブレーキ・グリップ・ドリフト・重量・耐久力・駆動方式・見た目 |
| `physics.ts` | 車両物理 (ステアリング、グリップ、ドリフト、駆動方式ごとの癖、衝突、コースアウト復帰 2 秒 など) |
| `npc.ts` | NPC 難易度 (Weak / Normal / Strong / Ultimate) ごとの能力レンジ、性格、レーシングライン・速度計画、回避・追い越し |
| `battle.ts` | タイヤHP、銃 (連射間隔・弾速・射程・ダメージ・耐久力による軽減)、NPC 射撃 AI |
| `items.ts` | アイテム抽選確率、所持数、Boost 効果、弾数、ボックス再出現時間 (8 秒) |
| `courses/*.ts` | コース形状 (制御点・バンク角)、**種類 (`raceType`: circuit / pointToPoint)**、道幅、路肩の種類 (壁/ガードレール/芝/落下)、ギミック配置、アイテムボックス位置、色、天候、見せ場・攻略。1コース1ファイル |
| `gimmicks.ts` | 路面ごとのグリップ・加速・抵抗 (砂・濡れ・石畳・磁力も)、ブーストパッド、**加速ゲート・スリップストリーム・水しぶき・動く足場・跳ね橋・落下物・トンネル加速**、ジャンプ、水中変形、横風、障害物、シーソー、バンク、NPC のギミック利用 |
| `courseQuality.ts` | Road Safety Corridor (地形・背景物が道路にかからない帯) と地形の高さ制限、コース構造検査の基準 |
| `courseInfo.ts` | コース選択の ★ の意味・目安タイムの平均速度・ギミックのアイコン |
| `controls.ts` | キー割り当て |
| `graphics.ts` | 画質プリセット (低/中/高)、カメラ演出 (コースの先を見る注視点)、夜の視認性 (ヘッドライト・誘導灯)、天候の粒子 |
| `audio.ts` | 効果音の音量・エンジン音 |
| `music.ts` | BGM の音量・曲の構成・ジャンルごとの楽器とリズム |
| `musicThemes.ts` | コースごとの曲 (ジャンル・キー・テンポ・コード進行・メロディの種 `seed`) |
| `themes.ts` | UI テーマ 4 種 (Arcade / Futuristic / Japanese Touge / Neon) |
| `game.ts` | 周回数、カウントダウン、ゴール後の待ち時間、グリッド、POINT TO POINT の助走路・退避路の長さ |

調整例:

- **BGM のメロディを変えたい** → `musicThemes.ts` の該当コースの `seed` の数字を変える (テンポは `bpm`、雰囲気は `style`)
- **BGM が大きすぎる** → 設定画面の「BGM の音量」、全体の上限は `music.ts` の `masterGain`
- **CPU が少し速すぎる** → `npc.ts` の該当難易度の `cornerSpeedFactor` / `brakingFactor` を少し下げる
- **ドリフトしにくい** → `physics.ts` の `drift.baseGripMul` を下げる、または車の `drift` を上げる
- **弾が強すぎる** → `battle.ts` の `gun.baseDamage` を下げる / `fireInterval` を上げる
- **氷が滑りすぎる** → `gimmicks.ts` の `surfaces.ice.grip` を上げる
- **ブーストパッドが強すぎる** → `gimmicks.ts` の `boostPad.maxSpeedMul` / `kick` を下げる
- **夜コースが暗い** → `graphics.ts` の `nightVisibilityConfig.headlights.intensity` を上げる、またはコースの `ambientIntensity` を上げる
- **スリップストリームが強すぎる** → `gimmicks.ts` の `slipstream.maxSpeedBonus` を下げる
- **コースを追加** → `src/config/courses/` にファイルを追加して `index.ts` の `COURSES` に並べ、`types.ts` の `SceneryKind` と
  `src/courses/CourseView.ts` の背景ビルダーに登録。ギミックは `gimmicks` 配列に並べるだけ。
  `npm run check:courses` (重なり・構造・安全帯) と `npm run sim` (NPC 完走) で確認 (詳しくは `docs/courses/README.md`)

## オフラインについて

- 実行時に CDN・外部フォント・外部画像・外部 3D モデル・外部音声・外部 API を一切使いません
- 3D モデル (車・背景) はコードで生成、テクスチャは Canvas で実行時生成、音は Web Audio で合成、
  フォントは OS 標準フォントのみ
- `npm install` はオンラインで1回だけ必要。以降の `npm run festival` はオフラインで動きます

### オフライン検証の手順 (リリース前)

1. `npm run festival` で起動
2. Chrome の DevTools (F12) → Network タブ → 「Offline」を選択してページを再読み込み
3. タイトル / PURE RACE 1P・2P / NPC / BATTLE DUEL / 3 コース / 音 / 設定保存 が動くことを確認
4. Network タブで localhost 以外へのリクエストが 0 件であること

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| ゲームを再起動したい | ブラウザを再読み込み (F5 / Cmd+R)。直らなければターミナルで Ctrl+C → `npm run festival:serve` |
| 画面が固まった・重い | 設定 → グラフィック品質 → 低。ブラウザの他のタブを閉じる |
| 音が出ない | 一度キー入力かクリックをする (ブラウザの自動再生制限)。設定の効果音音量、PC の音量を確認 |
| キーが効かない | ゲーム画面を一度クリックしてフォーカスを戻す。IME (日本語入力) を OFF にする |
| 2人で同時押しすると一部効かない | キーボードの同時押し制限 (ゴースティング) です。別のキーボードを使うと改善することがあります |
| マウスの照準が動かない | ゲーム画面をクリック (ポインターロック)。設定でマウス感度を調整 |
| 保存データを消したい | 設定 → ベストタイムを消す。全設定の初期化は DevTools → Application → Local Storage → `club-racing-festival:v1` を削除 |
| フルスクリーンにしたい | F11 (Mac: Ctrl+Cmd+F)、または 設定 → フルスクリーン |
| `npm run festival` でブラウザが開かない | 手動で Chrome を開き `http://localhost:4173` へ |
| ポート 4173 が使用中 | 前回のサーバーが残っています。ターミナルを閉じる / PC を再起動 |
