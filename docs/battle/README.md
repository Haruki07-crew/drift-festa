# BATTLE DUEL

- **タイヤHP**: 車全体で1つ、初期 100。0 で最高速度 50%。Recovery で全回復 (満タン時は使用不可)
- **ダメージ**: `baseDamage × (1 - durabilityReduction × (耐久力-1)/9)` (`battle.ts`)
- **銃**: Gun アイテム = 銃 + 10 発 (1 枠)。長押しで `fireInterval` ごとに連射
- **弾丸**: 速度 = 銃口速度 × 方向 + 車の速度ベクトル (慣性)。重力なし。最大飛行時間・最大射程で破棄。
  オブジェクトプール (64 発)。前回位置→現在位置の線分で当たり判定 (すり抜けなし)
- **アイテム**: 最大 3 個。ボックスは `courses.ts` で位置を管理、取得後 8 秒で再出現。満杯なら取得せず箱も消えない。
  抽選は重み付き (既定は全て同確率)。開始時 Recovery を 1 つ所持
- **Boost**: 8 秒間 最高速度 +20%・弾速 +40%。重ね掛けなし (再使用で残り時間を 8 秒へ)
- **射撃 AI** (`BattleAI.ts`): 反応時間ごとに偏差射撃の解 (PredictiveAim) を計算し、難易度に応じた
  予測精度・照準誤差を加える。発射判断確率・弾薬節約あり。強制命中なし。前方 ±70° のみ射撃
- **AI のアイテム**: HP が閾値以下で Recovery、前方が長い直線なら Boost、空きがあればボックスへ寄せる
