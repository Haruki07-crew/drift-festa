# NPC

「基本レーシングライン + リアルタイム補正」方式。車の性能には一切手を加えない (ラバーバンドなし)。

## 難易度
WEAK / NORMAL / STRONG / ULTIMATE (最強)。車の性能は変えず、運転の精度だけで強さを変える。
最強も「上手いから強い」: 正確なライン・ブレーキング・反応・低いミス率・ギミック/路面の理解・接触回避。
ラバーバンド・ワープ・性能ブーストは使わない。性格による崩れ (ミス増など) は難易度が高いほど小さく
(`personalityInfluence`)、ミス率・揺らぎには下限を設けて完全無欠にはしない。

## パターン (src/npc/NpcPatterns.ts)
- コース × 難易度ごとに 30 個、コースIDと難易度をシードに決定的生成 (同じ ID は常に同じ内容)
- ID: `<コース接頭辞>_<難易度>_<番号>` 例 `TOUGE_STRONG_017` / `AQUA_ULTIMATE_001`。4難易度 × 30 = 120 / コース、10コースで 1200
- パラメータ: ライン混合率・ラインオフセット・コーナー速度係数・ブレーキ想定・ブレーキマージン・直線速度・
  反応時間・ステア揺らぎ・ミス率/大きさ・追い越し傾向・前方注視時間・認識距離倍率・路面の理解度・
  ギミック利用傾向・障害物予測の精度・ドリフト傾向・ブロック傾向・使用車
- 性格 7 種 (Balanced / Aggressive / Defensive / Drift / Grip / Speed / Conservative) を均等に割当
- レース開始時に該当難易度の 30 個から重複なしでランダム選択

## 基本ライン (src/npc/RacingLine.ts)
- 理想ライン: 弾性バンド法で曲率を小さくする横オフセット列 (コースごとに1回計算・キャッシュ)
- パターンのラインは「中心線と理想ラインを lineBlend で混合 + lineOffset」
- 速度計画: ライン曲率 × グリップ / ステア性能からコーナー限界速度 → ブレーキ性能 × brakingFactor で後ろ向きに減速区間 → brakeMargin 分早める

## リアルタイム補正 (src/npc/NpcDriver.ts)
- Pure Pursuit の目標曲率を車の物理モデルで逆算してステア量にする
- 前方車両: 追い越すか判断 → 次コーナーの内側を優先して左右へ回避 / 無理なら車間を取って追従
- 後続車のブロック (Defensive 等)、接触後はラインへ滑らかに復帰 (急に戻らない)
- スピン・逆向き → recovering (低速で向きを直す)、動けない → reversing (後退)、それでも動けない → 復帰要求
- ミス (ブレーキ遅れ・大回り・アクセル抜け・ふらつき) を難易度と性格に応じた頻度で発生
