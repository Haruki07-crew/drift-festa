# 車両物理

自前のアーケード寄り物理 (`src/physics/VehiclePhysics.ts`)。パラメータは `src/config/physics.ts` と `cars.ts`。

1. **前後**: `accel × (1 - (v/vmax)^powerCurveExponent)`、ブレーキ、停止付近でブレーキ→後退、惰性・転がり抵抗
2. **回頭**: 目標ヨーレート = ステア × maxYawRate × handling × 低速係数 (停止中は曲がらない) × 高速係数 `1/(1+(v/v½)²)`
   → 高速ほど旋回半径が大きくなる
3. **横滑り**: 車体の向きを回してもワールド速度は慣性で残る → 横速度が発生し、横グリップ (摩擦上限) で打ち消す
4. **ドリフト**: キー押下中は横グリップを低下 (車の drift 値・駆動方式で変化)、回頭を強化。
   横滑り方向へ切るとカウンターステアとして回頭が穏やかになる。FR/MR はアクセルでパワーオーバー
5. **駆動方式** (`drivetrains`): FF=扱いやすい / FR=ドリフトしやすい / MR=キレるがシビア / AWD=安定・立ち上がり強い
6. **姿勢安定アシスト**: 非ドリフト時は横滑り角を減らす方向へ車体を向ける (スピンしにくい)
7. **コース**: 路肩の種類ごとに 壁 (反射 + 減速 + 向き補正) / 芝 (グリップ・最高速低下) / 落下 (空中 → 復帰)
8. **車同士**: 前後 2 円で近似。質量の逆数比で押し出し、1 回の接触での速度変化に上限 (吹き飛ばない)

調整の目安: 曲がらない → `steering.maxYawRate` / 車の `handling`、滑りすぎ → `grip.lateralGripAccel`、
ドリフトが戻らない → `drift.gripRecoveryRate`。
